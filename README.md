# Schwap - Forza Horizon 6 Audio Swapper

Instead of the StringTable replacement where you change your game language, with this you can keep your game language as-is by replacing the voiceover audio directly.

## Usage

When you [download Schwap from the latest release](https://github.com/Sainan/fh6-audio-swap/releases), you will get a Schwap.exe and Schwap.bat. Place these files into the ForzaHorizon6 folder (the one where forzahorizon6.exe is).

If you just want to have Japanese audio while the game language is set to English, double-click Schwap.bat, which does the following:
```
Schwap.exe EN JP
```

To apply another change, edit the .bat file with the format `Schwap.exe <game language> <audio language>`;
- `EN` - English
- `JP` - Japanese
- `CN` - Chinese (Simplified)
- `TW` - Chinese (Traditional)
- `DE` - German
- `IT` - Italian
- `KO` - Korean
- `BR` - Portuguese
- `ES` - Spanish (Spain)
- `MX` - Spanish (Mexico)

To undo any changes, run Schwap.exe without any arguments (double-click it).
